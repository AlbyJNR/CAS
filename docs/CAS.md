# CAS design notes

## Direction

An understated, cinematic TV interface: charcoal (#08090B), near-white (#F5F5F7), Inter medium/semibold and an uppercase, spaced CAS wordmark. Original CAS branding takes inspiration from the restraint of Apple TV without using Apple logos or fonts.

## Implemented

- Trailers as files (1.7.0, taken from upstream Alder 1.3.1's idea): `imdbTrailerStreams()` asks IMDb's GraphQL video service for the title's trailer (MP4/HLS, 1080p→SD) and `Meta.trailerFiles` takes an add-on's own `trailerStreams` URLs; `Screen.showTrailerClip` plays them in the box through CAS's ExoPlayer, falling back to the YouTube routes only when no file exists. Upstream remote is added as `upstream`; a full merge of 1.3.1 (~60 conflict hunks in 14 files) is the agreed next step.
- Preview: the box (Screen.openBox) with CAS's own ExoPlayer, fed by the same add-on list, filter and ranking as the sources page (streamAddons / wantedSource / rankSources in StreamsActivity.kt), starting at 12% for titles over 10 minutes and closing after 60 s. Debug builds open it from `adb shell am start ... --es preview <direct url>`.
- The mark is an aperture (a C with a dot), generated with the banner and icon by `tools/cas_brand.py`, and as `drawable/ic_mark.xml` for `Screen.brand()`.
- Browse-by-genre tiles in Search were tried in 1.4.0 and removed in 1.4.1 at Alan's request; the genre chips on Shows and Movies remain.
- Trailers: Fire OS's WebView sends video to a surface the box can't show, so Fire TV opens the YouTube app (`vnd.youtube:` then the web link); other TVs use the box, which probes itself and switches a TV to the app when it draws no frame. Settings › Title page › Trailers play overrides.
- Adaptive launcher icon (charcoal plate, wordmark inside the safe zone) and a matching Android 12+ splash, so launchers and the system splash never show the mark boxed. Banner and logo are regenerated by `tools/cas_brand.py` with a quiet vertical gradient.
- CI refreshes the `cas-preview` release's CAS.apk on every push, so the Downloader address is permanent.
- CAS launcher icon, TV banner, Watch Next mark and onboarding copy.
- Shared sans-serif display typography across home, detail, profile and settings screens.
- Neutral gradients, glass panels and white accent/focus treatments.
- Home: wordmark at left, centred navigation capsule, profile at right; clock removed from browsing header.
- Selected destination retains a grey fill; remote-focused destination is white with dark text.
- Library replaces My List in the primary navigation.
- 18 dp card gaps, 10 dp home card corners, reduced 1.06x focus growth and a narrower hero text block.
- Quiet gradient background for onboarding; existing profile film artwork still loads when available.

## Validation before release

A passing CI build verifies compilation and the existing unit suite, not visual layout or playback on a television. Check these on hardware before publishing:

1. Install on the TV; confirm the CAS name, icon and banner in the launcher and the charcoal splash on Android 12+.
2. Create a profile, sign in and check large-font onboarding text and code visibility.
3. Use D-pad left/right across Search, Home, Shows, Movies, Library and the profile button. Confirm Up/Down returns between header, hero actions, genre chips and cards.
4. Inspect the home header and hero text at 720p, 1080p and 4K, including the TV's enlarged text setting.
5. Check card focus at both edges of rows and all six library columns; no clipping or overlap.
6. Check detail pages, source menus, subtitles, profile picker and settings for readable text over bright artwork.
7. Play/resume a film and a series, test next episode and verify progress sync.
8. Confirm the update checker only uses AlbyJNR/CAS releases. Publish only CAS APKs signed with the same private release key.

Source packages remain `dev.alder` to avoid unnecessary refactoring; Android application ID is `uk.albyjnr.cas`.

## Ideas kept for later (2026-10-29)

Agreed with Alan to keep, in his order of interest; 2 and 5 were taken on first.

1. **Catch up**: on a series part way through, a button beside Resume plays the minute before the resume point in the preview box.
2. **Preview any episode**: Right on an episode in the guide previews it (hold OK stays "every source"). *(done in 1.6.0)*
3. **Surprise me**: a Library button that picks a random unwatched title and opens its preview; OK plays, Back spins again.
4. **Living posters**: resting on a title on Home for a few seconds cross-fades the hero art into a muted preview clip. Off by default, a setting, a delay before it fires: every hover fetches a debrid stream.
5. **Idle cinema**: the screensaver already in MainActivity (Continue Watching art, a clock), as a setting. *(done in 1.6.0)*
6. **Kids profile**: a profile flagged Kids shows family catalogs only, hides Settings, and leaves only with the PIN. About a day.
7. **What you'll get**: a quiet "4K · Dolby Vision · Atmos" line on the title page for what Play would pick, once sources are known.
8. **New episode first** on Home with a NEW mark. *(done in 1.8.0)*
9. **Background picture lag** switching TV ↔ Movies: the next pages' first titles are now warmed fully while on Home. *(done in 1.8.0)*
